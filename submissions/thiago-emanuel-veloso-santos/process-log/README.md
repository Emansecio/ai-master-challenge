# Registro do processo

A [narrativa escrita da construção](../solution/analise/PROCESSO.md) reúne minha participação, as ferramentas utilizadas e 14 rodadas documentadas até as correções finais. Esse formato é aceito pelo guia oficial. A organização do pacote de entrega é uma etapa posterior, registrada em [docs/ENTREGA.md](../docs/ENTREGA.md).

| Para conferir | Registro |
|---|---|
| Ideia inicial e mudanças de entendimento | [Proposta inicial](../solution/PROPOSTA-INICIAL.md) e [avaliação dos dados](../solution/analise/AVALIACAO-TECNICA.md). |
| Resultado real do classificador | [Ensaio Jev](../solution/analise/RESULTADO-JEV-VERCEL.md), com recibos e critérios de avaliação. |
| Alternativa examinada e descartada | [Router](../solution/analise/RESULTADO-ROUTER-LOCAL.md), com resultados preservados. |
| Escolha de linguagem e banco | [Arquitetura](../solution/STACK-ARQUITETURA.md). |
| Revisões antes da entrega | [Cinco revisões](../solution/app/evidence/skills-review/RELATORIO.md). |
| Problemas encontrados e corrigidos | [Correções verificadas](../solution/app/evidence/post-review-fixes/RELATORIO.md). |

Os relatórios anteriores preservam o estado de cada etapa. Datas, caminhos do código e quantidades de testes podem se referir àquela versão. O relatório de entrega identifica as verificações atuais. As capturas mostram a aplicação. Credenciais e exportações privadas não fazem parte deste pacote.
