# Dados utilizados

O ZIP desta pasta contém o dataset [CRM Sales Predictive Analytics](https://www.kaggle.com/datasets/agungpambudi/crm-sales-predictive-analytics), indicado pelo desafio 003. O enunciado informa licença CC0. A cópia foi mantida para permitir a execução com os mesmos dados auditados, sem depender de uma conta do Kaggle durante a instalação.

Arquivo: `crm-sales-predictive-analytics.zip`, 145.926 bytes.

SHA-256: `74d535826330b616758ebb6bb393abf701a5126364a72fbe71003cb6a7a87a9c`.

A aplicação verifica essa assinatura antes da importação. São 8.800 oportunidades no histórico, das quais 2.089 estão abertas, além das tabelas de contas, produtos e vendedores. A referência temporal da análise é 31/12/2017.

Os dados são públicos e históricos. Não representam a carteira atual da G4. Os limites e as verificações estão na [avaliação técnica](../AVALIACAO-TECNICA.md).
